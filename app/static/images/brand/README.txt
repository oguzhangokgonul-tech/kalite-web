TOKEN marka dosyaları - v2

Bu pakette token-logo-horizontal-white.png dosyası güncellendi.
Artık içinde sağ tarafta büyük "TOKEN" yazısı yoktur; sadece logo/sembol görseli vardır.

Dosya kullanımı:

1. token-logo-horizontal.png
- Açık renkli arka planlarda kullanılacak yatay logo.
- Login ekranı, landing page ve geniş marka alanlarında kullanılabilir.

2. token-sidebar-logo.png
- Sol sidebar marka alanında kullanılabilir.

3. token-icon.png
- Kare / sembol gereken alanlarda kullanılabilir.

4. token-logo-horizontal-white.png
- Koyu arka planlı alanlarda kullanılacak sembol-only görsel.
- İçinde yatay TOKEN yazısı yoktur.
- Sidebar küçük logo, koyu zeminli marka alanı veya sadece ikon gereken alanlarda kullanılabilir.

5. token-logo-symbol-only.png
- token-logo-horizontal-white.png ile aynı sembol-only alternatiftir.
- Codex için daha anlaşılır isimlendirme amacıyla eklenmiştir.

6. token-app-icon.png
- Uygulama ikonu / PWA ikonu için kullanılabilir.

7. favicon.png / favicon.ico / favicon-32.png / favicon-16.png
- Tarayıcı sekmesi favicon dosyalarıdır.

- tokenkalite-icon.png
